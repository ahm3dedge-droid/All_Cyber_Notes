# SPF (Sender Policy Framework)
## SPF in One Sentence

**SPF checks whether the sending mail server’s IP address is allowed to send email for the domain.**

---

## SPF Workflow (Very Short)

1️⃣ Email is sent  
2️⃣ Receiving mail server gets the email  
3️⃣ It reads the **MAIL FROM domain**  
4️⃣ It looks up the domain’s **SPF (TXT) record** in DNS  
5️⃣ It compares **sender IP vs allowed IPs**  
6️⃣ Result = **PASS or FAIL**

---

## Outcomes

### ✅ If SPF PASSES

- Sender IP is authorized
    
- Email is trusted
    
- Helps pass **DMARC**
    
- Usually delivered to **Inbox**
    

### ❌ If SPF FAILS

- Sender IP is NOT authorized
    
- Email marked suspicious
    
- **DMARC policy decides**:
    
    - `none` → delivered (warning)
        
    - `quarantine` → spam
        
    - `reject` → blocked
        

---

## What SPF Checks (Important)

|SPF Checks|SPF Does NOT Check|
|---|---|
|Sending server IP|Email content|
|MAIL FROM domain|Visible “From” name|
|DNS SPF record|Attachments|

---

## Key Rules to Remember 🧠

- SPF works on **IP address**
    
- SPF uses **MAIL FROM**, not “From:”
    
- SPF alone doesn’t block mail → **DMARC enforces**
    
- One domain = **one SPF record**
    

---

## Simple SPF Record Example

```
v=spf1 include:_spf.google.com -all
```

Meaning:  
➡️ Only Google mail servers can send mail for this domain  
➡️ Everyone else = FAIL

---

## One-Line Memory Trick

> **SPF = “Is this server allowed to send email for this domain?”**
