# 3. DMARC (Domain-based Message Authentication, Reporting, and Conformance)
## DMARC in One Sentence
**DMARC tells receiving mail servers what to do if SPF and/or DKIM fail.**

---

## DMARC Workflow (Very Short)
1️⃣ Email is received  
2️⃣ Receiver checks **SPF**  
3️⃣ Receiver checks **DKIM**  
4️⃣ DMARC checks **alignment** with the “From” domain  
5️⃣ DMARC applies the **policy**  
6️⃣ Final action = **Deliver / Spam / Reject**

---

## DMARC Logic (Core Rule)
```
(SPF PASS + aligned)
        OR
(DKIM PASS + aligned)
            ↓
        DMARC PASS
```

❌ If **both fail or are not aligned** → DMARC FAIL

---

## Outcomes

### ✅ If DMARC PASSES

- Email is authenticated
    
- Trusted by receivers
    
- Delivered to **Inbox**
    
- Reporting data is collected
    

### ❌ If DMARC FAILS

Action depends on **DMARC policy**:

| Policy         | Meaning      | Result             |
| -------------- | ------------ | ------------------ |
| `p=none`       | Monitor only | Delivered (logged) |
| `p=quarantine` | Suspicious   | Sent to spam       |
| `p=reject`     | Block it     | Rejected           |

---

## What DMARC Checks

| DMARC Checks       | DMARC Does NOT Check |
| ------------------ | -------------------- |
| SPF result         | Email content        |
| DKIM result        | Malware              |
| Domain alignment   | Attachments          |
| Policy enforcement | Encryption           |

---

## Alignment (Very Important)
**Alignment = same domain as “From:”**

| Method       | Example                   |
| ------------ | ------------------------- |
| SPF aligned  | MAIL FROM = `company.com` |
| DKIM aligned | `d=company.com`           |
| Visible From | `user@company.com`        |
➡️ At least **one must align**.

---

## Simple DMARC Record Example
```
v=DMARC1; p=quarantine; rua=mailto:dmarc@company.com
```

Meaning:
- Enforce DMARC
- Send failures to spam
- Send reports to mailbox
---

## Key Rules to Remember 🧠
- DMARC **does not replace** SPF or DKIM
- DMARC **uses their results**
- DMARC controls **final action**
- DMARC provides **visibility via reports**

---

## SPF vs DKIM vs DMARC (One-Line)

|Control|Question it answers|
|---|---|
|SPF|Who can send?|
|DKIM|Was it changed?|
|DMARC|What should we do?|

---

> **DMARC = “If authentication fails, what’s the rule?”**
