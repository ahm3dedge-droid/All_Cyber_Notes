### TCP/IP Model Layers
#### 1. Network Interface: 
The Network Interface layer is also known as the Link Layer. It describes how a host accesses the network. For example, copper wire (Ethernet), fiber optics, or radio spectrum (wireless).

#### 2. Internet: 
The Internet layer determines the routing decisions based on the protocol being used and the information in the data packet.

#### 3. Transport: 
The Transport layer ensures protocols are followed in [host-to-host communications](https://electricalacademia.com/computer/host-host-communication-comptia-network/).

#### 4. Application: 
The Application layer is responsible for the protocol needed for an application to run. It specifies which ports and sockets are needed for the application.
